# Network Protocols

## Introduction

A network protocol is a set of rules that defines how devices communicate and exchange data over a network.

This section covers four important protocols:

* HTTP / HTTPS
* FTP
* DNS
* DHCP

---

## 1. HTTP

HTTP stands for Hypertext Transfer Protocol.

### What does it do?

HTTP is used to transfer information between a web browser and a web server.

It defines how requests and responses are exchanged.

### Where is it used?

HTTP is used for accessing websites and web-based services.

### Example

When a user visits a website, the browser sends an HTTP request to the web server and receives a response.

---

## 2. HTTPS

HTTPS stands for Hypertext Transfer Protocol Secure.

### What does it do?

HTTPS provides secure communication between a client and a web server by using encryption.

It helps protect data from being easily read or modified while it is being transmitted.

### Where is it used?

HTTPS is widely used for:

* Websites
* Online banking
* Online shopping
* Login pages
* Web applications

### Example

When a user logs into an online account, HTTPS helps protect the information exchanged between the browser and server.

---

## 3. FTP

FTP stands for File Transfer Protocol.

### What does it do?

FTP is used to transfer files between computers over a network.

It can be used to upload files to a server or download files from a server.

### Where is it used?

FTP has traditionally been used for:

* File uploads
* File downloads
* Server file management

### Example

An administrator can use FTP to transfer files between a computer and a server.

---

## 4. DNS

DNS stands for Domain Name System.

### What does it do?

DNS translates human-readable domain names into IP addresses.

For example:

```text
example.com
     ↓
IP address
```

This allows users to access websites using names instead of remembering numerical IP addresses.

### Where is it used?

DNS is used whenever a domain name needs to be resolved to an IP address.

### Example

When a user enters a website name into a browser, DNS can help determine the IP address of the corresponding server.

---

## 5. DHCP

DHCP stands for Dynamic Host Configuration Protocol.

### What does it do?

DHCP automatically provides network configuration information to devices.

This can include:

* IP address
* Subnet mask
* Default gateway
* DNS server information

### Where is it used?

DHCP is commonly used in home, office, college, and enterprise networks.

### Example

When a laptop connects to a Wi-Fi network, the router's DHCP service can automatically assign an IP address to the laptop.

---

## Protocol Summary

| Protocol | Full Form                           | Main Purpose                    | Common Use            |
| -------- | ----------------------------------- | ------------------------------- | --------------------- |
| HTTP     | Hypertext Transfer Protocol         | Web communication               | Websites              |
| HTTPS    | Hypertext Transfer Protocol Secure  | Secure web communication        | Secure websites       |
| FTP      | File Transfer Protocol              | File transfer                   | Upload/download files |
| DNS      | Domain Name System                  | Name resolution                 | Domain to IP address  |
| DHCP     | Dynamic Host Configuration Protocol | Automatic network configuration | Wi-Fi/LAN networks    |

## Conclusion

Network protocols provide standardized rules that allow different devices and applications to communicate. HTTP/HTTPS, FTP, DNS, and DHCP perform different but important functions in everyday networking.
